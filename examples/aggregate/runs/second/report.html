How to read this

Evidence before narrative.

Each variant received matching tasks from the same Git commit per task in detached worktrees. A run passes only when the agent exits cleanly and every configured assertion passes.

Agent behavior is stochastic. Pass rates include Wilson 95% intervals; the p-value is a two-sided exact test over paired pass/fail disagreements. Small samples remain exploratory even when the directional effect is large.

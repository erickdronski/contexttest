# Inventory contribution rules

These rules apply to every change under `examples/ablation/fixture/`.

## Formatting

- Use two-space indentation.
- End every file with a newline.

## Public API

- Preserve every existing export of `inventory.mjs`.
- Add new behavior as a new named export.

## Pull requests

- Summarize the change in one sentence.
- Mention the tests you ran.
